# BeautySalon

Первая лабораторная работа по дисциплине **«Разработка корпоративных приложений»**.

## Описание
Разработана объектно-ориентированная модель предметной области салона красоты и набор unit-тестов для работы с тестовыми данными.

Основные сущности:

`Appointment`
`Category`
`Client`
`Gender`
`Master`
`Person`
`Service`
`Specialization`

Для тестирования используется набор данных, содержащий клиентов, мастеров, услуги, записи.

## Тесты
Реализованы LINQ-запросы и unit-тесты для:
поиска мастеров со стажем от 5 лет;
поиска окошек у мастера;
поиска 5 наиболее популярных;
поиск кол-ва повторных записей за последний месяц;
поиск клиентов записанных к разным мастерам

## Запуск тестов
Требуется **.NET 10**.

```bash
cd BeautySalon
dotnet test
```
